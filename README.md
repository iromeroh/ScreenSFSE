# ScreenSFSE

Native plugin and Papyrus source for ScreenSFSE **0.3.3** for Starfield.

## Build

Requires Windows x64, Visual Studio 2022 with Desktop development with C++, a
Windows SDK, CMake 3.21 or later, Git, and the pinned CommonLibSF dependencies.
See [BUILDING.md](BUILDING.md) for dependency setup and build commands.

Use the resulting DLL with the ScreenSFSE 0.3.3 mod assets, SFSE, and
Address Library for your game version. Game assets are distributed separately.
